# 0.9.24.1 Phase-Locked Empty Atlas Fix

## 修复

- 空的或尚未完成 NBT 同步的弧方块不再调用 `segments.get(0)`，直接跳过本帧并等待数据到达。
- 删除内外弯分别推进 U 坐标的做法。所有横向位置共用同一个中心线进度，棋盘格径向列保持对齐。
- 首尾纹理相位只求解一次，并通过一个全局均匀倍率铺完整条弧；不再用 smoothstep 在弧中逐渐扭转 UV。
- 端面继续按真实截面坐标映射。

## 使用

旧的 0.9.24 弧建议拆除后重新生成。工作流：`Build 0.9.24.1 Phase Locked Empty Atlas Fix`。
