# 0.9.24 Native Seam / Offset Surface Metric / Endpost Fix

本版只针对 0.9.23 实测暴露的三个底层问题：

1. 首尾端点上、下、左、右表面与弧体出现白接白、黑接黑；
2. 长弧的内外侧仍然出现棋盘格被压缩或拉长；
3. 弧栏杆首尾内侧的小柱重复、变粗，连接普通栏杆后旧错误小柱仍然残留。

## 普通弧带纹理

0.9.23 仍然让内弯、外弯共用中心线长度。圆弧转弯时，外侧真实长度比中心线长，内侧真实长度比中心线短，所以必然会产生拉伸和挤压。

0.9.24 改为四角表面长度度量：

- 每一段分别计算 `左下、右下、左上、右上` 四条真实偏移曲线的长度；
- 任意顶点的纹理纵坐标由四角长度双线性插值得到；
- 内弯使用内弯真实长度，外弯使用外弯真实长度；
- 长弧不再把一张中心线纹理强行套给所有侧面。

首尾相位不再假定从 0 开始：

- 起点读取弧线一侧“虚拟普通方块”的原生面坐标；
- 终点读取另一端虚拟普通方块的原生面坐标；
- 使用同一材质面变换反算目标 UV；
- 只在整条弧上平滑分摊最多半格的相位误差；
- 起点和终点都能使用与普通相邻方块相同的 0/1 边缘方向。

旧的 `UnifiedSurfaceArcRenderer` 已从源码删除，防止中心线/周长旧逻辑再次被误用。

## 弧栏杆首尾小柱

- 弧线不再伸入端点方块 `2/16` 格；
- 中间模型从端点连接面外侧 `1/64` 格开始；
- 两个原生端点的连接臂负责真正的端面衔接；
- 首段和末段会被明确标记；
- 只裁掉首尾附近的局部小柱、装饰柱等短几何；
- 横杆、底座等贯穿整个模块的连续几何不会被删除；
- 后续再连接普通栏杆时，不会保留一组重叠的旧端点小柱。

## 测试要求

旧弧与旧弧栏杆保存的是 0.9.23 几何和 section 数据，必须拆除后重新生成。
