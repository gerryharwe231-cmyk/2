# Slope Connector 0.9.22 — Independent Dimensions & Native Endpoints

Minecraft/Fabric: **1.20.1**

本版只处理三个问题：

1. 原“宽度”拆分为 **左右宽度** 与 **上下厚度**；
2. 首尾端点恢复为 Minecraft 原生方块渲染，使端点所有面继续与旁边普通方块使用同一套本地方块纹理；
3. 原版及 Conquest Reforged 的栏杆、围栏、墙、玻璃板端点，在弧线端和后续普通栏杆邻接时自动进入连接状态。

## 尺寸设置

手持连接杖按 **G** 打开面板：

- 原来的宽度行现在表示 **左右宽度**；
- 新增一行 **上下厚度**；
- 左右和上下互不影响；
- 上下厚度会在原始棱柱生成阶段修改，所以视觉、碰撞和自动裁切共用同一套实际尺寸。

命令备用：

```mcfunction
/slopeconnector lrwidth 3
/slopeconnector udwidth 2
/slopeconnector dimensions
```

`lrwidth` 范围为 1–32，`udwidth` 范围为 1–16。

## 端点纹理

0.9.21 仍会在端点方块表面绘制全局弧面覆盖层。把普通方块放到端点旁边时，覆盖层与普通方块本地 UV 不属于同一体系，因此会出现截图中的接缝错位。

0.9.22 改为：

- 不再渲染或保留端点 `SurfaceQuad` 覆盖层；
- 端点方块的顶、底、前、后、左、右六个面全部由 Minecraft 原生模型渲染；
- 弧带只渲染两个端点连接面之间的可见部分，端点内部重叠面会被裁掉，避免闪烁；
- 根据两端内部重叠距离求出可见弧长，并对整条弧统一进行极小幅度的 S 方向缩放；
- 起点连接面纹理相位为整数，终点连接面纹理相位也为整数，因此两头都能与原生端点纹理周期衔接。

## 栏杆端点连接

- 生成栏杆弧时，直接将两个端点朝弧线的一侧设置为连接状态；
- 邻居更新时识别原版 Fence、Pane、Wall，以及 Conquest 的 fence、railing、balustrade、bars、pane、wall 属性方块；
- 端点外侧后来放置普通栏杆时会重新计算连接状态；
- 移除普通栏杆时仍由原版/模组原有邻居逻辑负责断开；
- 方块支持判断带缓存，不会对每次普通方块更新反复执行反射扫描。

## 更新测试

旧弧保存着旧 SurfaceQuad 与旧尺寸，必须拆除并重新生成。`mods` 文件夹只保留新编译的 0.9.22 jar，不要同时安装 0.9.21。
